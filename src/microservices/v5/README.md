# Вариант 5: Tkinter-приложение для учета материалов

Приложение реализует профильный вариант из задания:

- создает SQLite-базу `warehouse.db` при первом запуске;
- хранит типы материалов, материалы, продукцию и нормы расхода материалов;
- показывает список материалов с остатком, минимальным запасом и требуемым количеством;
- подсвечивает материалы, у которых остаток ниже минимума;
- поддерживает поиск, добавление, редактирование и удаление материалов;
- содержит расчет количества продукции по формуле из модуля 4:

```text
Количество = stock / (param1 * param2 * coefficient * (1 + loss_percent / 100))
```

При некорректных данных расчет возвращает `-1`.

## Запуск

```bash
python3 app.py
```

Внешние зависимости не нужны: используется только стандартная библиотека Python (`tkinter`, `sqlite3`).
Если установленный через Homebrew `python3` запускается с ошибкой `No module named '_tkinter'`, используйте системный Python:

```bash
/usr/bin/python3 app.py
```

## Файлы

- `app.py` - основной код приложения и работа с базой.
- `warehouse.db` - локальная база, создается автоматически и не хранится в git.
