# Вариант 3: Tkinter-приложение для заявок партнеров

Приложение реализует базовый вариант из задания:

- создает SQLite-базу `orders.db` при первом запуске;
- хранит типы партнеров, партнеров, товары, заявки и товары в заявках;
- показывает список заявок с расчетом суммы;
- поддерживает поиск, фильтр по статусу, добавление, редактирование и удаление заявок;
- проверяет обязательные поля и количество товара.

## Запуск

```bash
python3 app.py
```

Внешние зависимости не нужны: используется только стандартная библиотека Python (`tkinter`, `sqlite3`).
Если установленный через Homebrew `python3` запускается с ошибкой `No module named '_tkinter'`, используйте системный Python:

```bash
/usr/bin/python3 app.py
```

## Файлы

- `app.py` - основной код приложения и работа с базой.
- `orders.db` - локальная база, создается автоматически и не хранится в git.
