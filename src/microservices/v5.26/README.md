# Вариант 5 2026: мебельный магазин на Python/Tkinter

Реализация по PDF-заданию `В5_2026.pdf`.

Что есть:

- SQLite-база `furniture_store.db`, создается при первом запуске.
- При наличии файлов в `assets` автоматически импортируются товары из `Tovar.xlsx`, пользователи из `user_import.xlsx` и заказы из `Заказ_import.xlsx`.
- Окно входа и вход гостем.
- Роли: гость, клиент, менеджер, администратор.
- Отображение ФИО пользователя в правом верхнем углу.
- Список товаров с категорией, описанием, производителем, поставщиком, ценой, единицей, остатком и скидкой.
- Подсветка товаров:
  - скидка от 15% - фон `#008080`;
  - нет товара на складе - серый фон;
  - сниженная цена - цена показывается как `старая -> итоговая`.
- Для менеджера и администратора доступны поиск, фильтрация по диапазону скидки и сортировка по цене/остатку.
- Для администратора доступны добавление, редактирование и удаление товаров.
- Удаление запрещено, если товар присутствует в заказе.
- Изображения товаров сохраняются в папку приложения, принимаются файлы не больше `300x200` пикселей.
- При отсутствии изображения используется заглушка `assets/picture.png`, которая создается автоматически.

Демо-пользователи:

```text
client / client
manager / manager
admin / admin
```

## Запуск

```bash
python3 app.py
```

Если Homebrew Python падает с `No module named '_tkinter'`, используйте системный Python:

```bash
/usr/bin/python3 app.py
```

Внешние зависимости не нужны.
